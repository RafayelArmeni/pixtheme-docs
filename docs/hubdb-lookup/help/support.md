# Support

We're happy to help with setup questions and anything that doesn't work as described.

**Email:** [support@pixtheme.com](mailto:support@pixtheme.com)

Please include:

* Your HubSpot account id (shown under your account name in HubSpot)
* The question you asked the agent, or the workflow and action that failed
* What you expected and what happened instead, with a screenshot if it helps

Support is in English.

Need a custom agent tool or HubDB setup for your site? See [HubSpot development services](https://www.pixtheme.com/).
