# Style settings

Open the module's **Style** tab.

## Color preset

| Preset | Best for |
|---|---|
| **Light** | White sections on light pages |
| **Dark** | Dark sections and dark themes |
| **Brand tint** | A light tint of your brand color, to make the table stand out from the sections around it |

## Brand color

**Brand color** is used for the highlighted column, badges, buttons, check icons and the switch. It follows your theme's primary color until you choose a different one.

## Custom colors

Override the preset with **Background**, **Text color**, **Border color**, **Included icon color** and **Not included icon color**. Leave a color empty to use the preset.

## Layout

* **Row height:** comfortable or compact.
* **Striped rows:** alternate row backgrounds for easier reading.
* **Corner radius:** 0 to 32 px.
* **Maximum width:** 600 to 1600 px. Use a smaller width for tables with 2 columns.

!!! note "Works with any theme"
    Many themes add their own colors and borders to tables. Smart Comparison Table resets those styles inside the module, so it looks the same in every theme.
