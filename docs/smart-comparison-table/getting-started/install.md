# Install the module

Smart Comparison Table is free on the HubSpot Marketplace.

1. In HubSpot, click the **Marketplace** icon in the top navigation and choose **HubSpot Marketplace**.
2. Open **Templates**, then **Modules**, and search for **Smart Comparison Table**.
3. Open the listing and click **Install for free**. Read the terms, tick the checkbox and confirm.

After installing, the module appears in the page editor's **Add** panel for website pages and landing pages. Search for "comparison" to find it quickly.

!!! tip "Try it on a draft first"
    Add the module to a new draft page to explore the settings before you use it on a live page.

## Updates

Updates from the Marketplace are applied to every page that uses the module. Field names never change between versions, so your content stays as it is.
