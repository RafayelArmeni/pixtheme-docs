# Changelog

## 1.0.0

First release.

* 2 to 6 columns with name, description, price, badge, highlight, logo and button
* Feature rows and section headings, with tooltips
* `yes`, `no` and `partial` icons, plus text values
* "Show differences only" switch
* Sticky bar with the column names on desktop, placed below the site header automatically
* Mobile layouts: swipe with fixed feature names, or one card per column
* Light, Dark and Brand tint presets, brand color from the theme, custom colors
* Screen reader labels you can translate
