# All modules

Every module has a **Content** tab and a **Style** tab ([Section style and the Style tab](../customize/style-tab.md)). Labels and button texts can be translated in each module's **Labels and translations** group.

## Properties

| Module | What it does |
|---|---|
| **Property Listings** | Properties from HubDB: all homes with search, filters and sorting, featured homes, similar homes, an agent's homes or homes in an area |
| **Property Cards** | Property cards you type in. Works without HubDB |
| **Property Details** | The property page: gallery with lightbox, key facts, description, features, floor plan, video, map, agent box, inquiry form and viewing button |
| **Mortgage Calculator** | Monthly payment from price, down payment, rate and term, with taxes and insurance. Uses the property price on property pages |
| **Unit Types** | Floor plan cards for a new development, with beds, size and price |
| **Availability Table** | Units with floor, size, price and availability status |

## People and places

| Module | What it does |
|---|---|
| **Agent Cards** | Team grid from HubDB or typed in |
| **Agent Profile** | The agent profile page: portrait, bio, languages, areas and contact buttons |
| **Neighborhood Tiles** | Area tiles from HubDB or typed in, with optional home counts |
| **Neighborhood Guide** | The area guide page: description, highlights and map |
| **Client Reviews** | Star ratings and quotes with an overall rating |
| **Logo Strip** | Logos of partners, press or tenants |

## Page building

| Module | What it does |
|---|---|
| **Home Hero** | Hero in 3 layouts, with property search, buttons and trust facts |
| **Page Intro** | Heading and text at the top of inner pages |
| **Service Cards** | Icon cards with links |
| **Image and Text** | Photo with stat card, text, checklist, buttons and stats |
| **Process Steps** | Numbered steps |
| **Photo Gallery** | Grid or mosaic gallery with lightbox |
| **FAQ** | Accordion of questions |
| **Call to Action Banner** | Banner with photo, heading and two buttons |
| **Latest Posts** | Recent posts from your blog |

## Forms

| Module | What it does |
|---|---|
| **Form Section** | Text and checklist next to a HubSpot form |
| **Contact Section** | HubSpot form with office details, opening hours and map |

## Site

| Module | What it does |
|---|---|
| **Site Header** | Logo, menu with dropdowns, phone, button, top bar and language switcher |
| **Site Footer** | Logo, text, social links, menu columns, contact details and legal notice |
| **Error Page** | Content for the 404 and 500 pages |
