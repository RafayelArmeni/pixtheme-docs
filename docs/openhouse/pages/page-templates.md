# Page templates

| Template | What's on it |
|---|---|
| **Home** | Hero with property search, featured properties, services, image and text, neighborhoods, agents, client reviews, call to action, latest blog posts |
| **Home – single agent** | Hero, logo strip, the agent's listings, image and text, how it works, client reviews, contact form, latest blog posts |
| **Home – luxury** | Full-screen photo hero, logo strip, curated listings, image and text, photo gallery, neighborhoods, call to action |
| **Home – commercial** | Hero, tenant logos, services, offices and retail spaces, image and text, how it works, leasing contact form, latest blog posts |
| **Home – new development** | Project hero, image and text, amenities, photo gallery, unit types, availability table, register-interest form, FAQ |
| **Property listings and property pages** | Listings with search, filters and sorting; property pages with gallery, key facts, features, floor plan, video, map, agent, inquiry form, mortgage calculator and similar homes |
| **Agents and agent profiles** | Team grid; profile pages with bio, contact buttons and the agent's listings; client reviews and call to action |
| **Neighborhoods and neighborhood guides** | Area tiles; guides with description, highlights, map and homes in the area; call to action |
| **Sell your home** | Valuation form, how selling works, image and text, client reviews, FAQ, call to action |
| **About** | Page intro, image and text, services, team, client reviews, call to action |
| **Contact** | Page intro, contact form with office details and map, FAQ |

Every template is built with drag-and-drop areas: move, remove or add modules and sections freely.

!!! note "Latest blog posts"

    The **Latest Posts** section shows posts from your HubSpot blog. If you don't have a blog yet, remove the section from the page.
