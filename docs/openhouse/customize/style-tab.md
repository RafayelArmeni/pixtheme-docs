# Section style and the Style tab

Every Openhouse content module has a **Style** tab in the page editor. Use it to make one section look different from the rest of the page. Empty fields keep the theme design, so you only set what you want to change.

## Section style

| Option | Result |
|---|---|
| **Same as the page** | Uses the page background (default) |
| **Light** | White background |
| **Soft (warm background)** | The soft, warm background from theme settings, to separate sections |
| **Dark** | Dark background with light text, great for calls to action |

!!! tip

    Alternate **Same as the page** and **Soft** down a long page to give it rhythm without changing any colors.

## Custom styles

For full control, open **Custom styles**:

| Group | Settings |
|---|---|
| **Spacing** | Space above and below the section, on desktop and on mobile |
| **Background** | Background color, background image, image overlay color and image position |
| **Text colors** | Headings, body text, secondary text, small labels, highlighted words and links |
| **Cards** | Card background, card border and card corner radius |
| **Buttons and accents** | Primary button color, text and hover color, accent color, card hover border |

## Highlighted words

Wrap words in a heading in `*asterisks*` to show them in the highlight style (italic, in your primary color):

```
Find a home you'll *love* in San Francisco
```

On dark sections, highlighted words use the accent color.
