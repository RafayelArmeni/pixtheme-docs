# Theme settings

Open theme settings from any Openhouse page: click the **Theme** icon in the left sidebar of the page editor, then **Edit theme settings**. Changes apply to every page.

| Group | Settings |
|---|---|
| **Brand** | Primary color, accent color, heading font, body font |
| **Colors** | Page background, soft section background, card background, border color, muted text, link color, dark section background, text on dark sections |
| **Buttons** | Corner radius, vertical and horizontal padding, text style |
| **Layout** | Maximum content width, section spacing on desktop and mobile, card corner radius, soft shadows on cards, fade sections in on scroll |
| **Property listings** | Currency, currency position, thousands separator, area unit |
| **Header** | Sticky header, header background, menu link colors, line under the header |
| **Blog** | Topic buttons, subscribe form, reading time, author on cards, share buttons, topics under posts, author box, related posts |
| **Footer** | Footer background, heading color, text color, link hover color |

!!! tip "Fonts"

    Openhouse looks best with a serif for headings (the demo uses Fraunces) and a clean sans-serif for text (Inter). For a more modern look, try a sans-serif for both.
